Visão Geral

Sobre o Sistema Desenvolvido

Este projeto foi desenvolvido por Daniele Amaro Facundo como parte do Checkpoint 03. O objetivo é demonstrar a manipulação avançada de dados em JavaScript puro através de funções modulares e reutilizáveis, gerenciando o estoque e o catálogo da Vinheria Agnello.

forEach

Listagem Completa

Percorre cada vinho cadastrado e imprime todos os detalhes no console (nome, tipo, safra e estoque).

lista.forEach(...)
filter

Estoque Baixo

Filtra e retorna apenas os vinhos que possuem menos de 5 garrafas disponíveis na adega.

lista.filter(v => v.estoque < 5)
reduce

Estoque Total

Calcula a soma acumulativa de todas as garrafas cadastradas no estoque da vinícola.

lista.reduce((acc, v) => acc + v.estoque, 0)
map

Nomes em Caixa Alta

Transforma o array de vinhos em um novo array contendo os nomes em letras maiúsculas.

lista.map(v => v.nome.toUpperCase())
